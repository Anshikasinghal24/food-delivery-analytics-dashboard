# 🍽️ Food Delivery Analytics Dashboard

## 📌 Project Overview

This project is developed for the **Internal Hackathon – Data Analytics**.

The project focuses on analyzing food delivery operations and converting raw delivery data into meaningful business insights using **Microsoft Power BI**.

The dashboard analyzes order demand, delivery performance, customer ratings, locations, traffic conditions, weather conditions, vehicle information, and multiple deliveries.

The objective is to build a clear and interactive analytics solution that can support data-driven operational decisions.

## 🎯 Problem Statement

Food delivery operations generate large amounts of data related to orders, customers, delivery personnel, locations, traffic, weather, and delivery times.

The objective of this project is to analyze this data and answer important operational questions such as:

- How does order demand vary across different cities?
- Which order types contribute to the overall order volume?
- How does delivery time vary across different locations?
- How are traffic conditions associated with delivery time?
- How do weather conditions relate to delivery performance?
- How does delivery time vary across different vehicle types?
- How are multiple deliveries associated with delivery time?
- How do customer ratings vary across cities and order types?

The final goal is to transform the raw dataset into an **interactive Power BI dashboard** that presents KPIs, visualizations, comparisons, and data-driven insights.

# 💡 Proposed Solution

We developed an interactive **Food Delivery Analytics Dashboard** using Power BI.
